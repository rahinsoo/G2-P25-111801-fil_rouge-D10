# User stories : 


En tant qu'Utilisateur, je souhaite :
1. Me connecter en toute sécurité afin d'accéder aux fonctionnalités de l'application. => page de connexion sécurisée.

En tant que Collaborateur, je souhaite :
1. Faire une saisie de mon temps par tâche déjà réalisé afin de rendre plus traçable mon effort de travail => page Tableau de bord avec calendrier et modale création tâche/ajout à une tâche.
2. Visualiser les projets auxquels j’ai été affectés afin de comprendre les besoins attendus => page Projets avec encart déroulant pour les détails. Notification quand on est affecté à une activité ??
3. Visualiser mes projets/tâches avec un historique pour organiser mon temps de travail =>tableau de bord visuel.
4. Compléter un calendrier pour mes absences afin de rendre visible mes disponibilités => page tableau de bord 
5. Accéder à mon profil et à ma fiche informations que je peux modifier afin de garantir les infos => page Profil.
6. Accéder aux paramètres de l’appli pour effectuer des choix de thème et avoir accès à la FAQ => page Paramètres.

En tant que Recruteur-placeur, je souhaite :
1. Enregistrer un nouveau client, afin ensuite de le lier à un projet => page Clients avec création, modification, archivage et appel API.
2. Enregistrer un nouveau projet, afin de le gérer => page Projets avec création, modification, suppression/annulation. Dans la création menu déroulant avec choix clients.
3. Découper le projet en tâches prévisionnelles. ??? est ce nécessaire pour la V1 => page Tâches.
4. Affecter un collaborateur à une activité => sur la page Projets.
5. Créer et consulter les fiches infos des collaborateurs de mon portefeuille pour les choisir de façon efficiente => page Collaborateurs.
6. Fixer pour chaque activité un TJM individuel par collaborateur ???
7. Visualiser les projets en cours, les tâches en cours, avec des jauges pour indiquer l’effort de travail, afin de situer l’avancement des projets => page Tableau de bord. Tant que rien n’est facturé, par défaut « à facturer » ???

En tant que Directeur (technique/commercial), je souhaite :
1. Visualiser tous les projets, tâches, clients, collaborateurs => accès à toutes les pages.
2. Création clients, projets 

En tant que service administratif, je souhaite :
1. Récupérer des rapports d’effort de travail par activité/projet, afin d’établir les factures progressivement. => page Projet avec pour chaque collaborateur, le temps effectué et le TJM.
2. Faire un retour sur ce qui est facturé pour que le statut soit modifié.
